# Remotion skills (not copied here)

Remotion's official agent skills live in [remotion-dev/skills](https://github.com/remotion-dev/skills).
That repo has no license file, so its contents are not redistributed here. Install them from the source:

```bash
npx skills add remotion-dev/skills
```

Or start a new Remotion project, which offers to add the skills:

```bash
npx create-video@latest
```

Skills in the pack (as of commit `a2824c6`, 2026-11-05): `remotion-best-practices` (umbrella),
`remotion-create`, `remotion-markup`, `remotion-captions`, `remotion-multimedia`, `remotion-render`,
`remotion-studio`, `remotion-maps`, `remotion-saas`, `remotion-interactivity`, `remotion-docs`,
`remotion-upgrade`, `remotion-license`.

Remotion itself is free for individuals and small teams. Larger companies need a company license:
[remotion.dev/docs/license](https://www.remotion.dev/docs/license).
