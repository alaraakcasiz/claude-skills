# Product and persona template

Fill one of these in for each product × persona pair before writing hooks. Keep filled-in copies next to this file (or in your own notes) so later sessions don't have to re-ask.

## Product

**What it literally does (mechanism):**
e.g. "iOS app that blocks chosen apps on a schedule and unlocks them exactly when the time ends."

**Positioning (one line):**
e.g. "Screen time harms focus; blocking apps helps you become 1% better."

**True claims you can use:**
- founder background / credentials that are actually true
- features that are live today

**Do not claim:**
- planned / beta features
- inflated authority (a famous institution that didn't build it)
- medical or clinical effects

**Payoff vocabulary** (what the user gets):
e.g. disciplined, locked in, focused, present, showing up, productive, monk mode, mornings back

**Enemy vocabulary** (what the product fights):
e.g. doomscrolling, the feed, blue light zombies, cheap dopamine, apps engineered to break your attention

**Unbranded hashtag pool:**
e.g. #screentime #doomscrolling #discipline #lockedin #monkmode #digitaldetox #1percentbetter #productivity #selfimprovement #focus

## Persona

- **Name / handle:**
- **Age, gender, location:**
- **Job and daily life:** (e.g. tech 9-5, morning runs, side project in the evenings)
- **Identity / register:** (e.g. "optimization bro, relatable not harsh" or "marketing girl, casual tool-discovery confessions")
- **Words they'd say:** (e.g. bro, the guy who…, built different / girl, obsessed, not me…)
- **Default scenes:** (e.g. run club, post-run coffee, desk setup, client call)
- **Visual rules:** self-filmed look, framing, clothing, accessories; character reference ID if using an AI video tool
- **Hook clip rules:** silent, ~4 s, 9:16, expression shift at ~2 s, no music
